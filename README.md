## Uruchomienie dowolnego projektu

```bash
cd single-page-fryzjer     # lub landing-page-saas / svelte-app-dashboard
pnpm install
pnpm dev                   # http://localhost:5173
```

## Stack

- **SvelteKit** + **Svelte 5** (runes: `$state`, `$derived`)
- **TypeScript**
- **Tailwind CSS v4** + **Skeleton UI v4**
- **pnpm**
- Ikony: `@lucide/svelte`
